Saudi Employee Iqama & Documents Management


Overview

```

Saudi Employee Iqama & Documents Management helps HR departments manage employee documents and automatically track expiration dates, send email notifications, and maintain complete renewal history.

```

Employee Documents Inside Employee Form

```

Documents are fully integrated inside the employee profile for easy access.

```

Centralized Documents Management

```

Manage all employee documents from one place with color-coded statuses.

```

Automatic Expiring Soon Notifications

```

Employees receive automatic email alerts when documents are about to expire.

```

Expired Documents Alerts

```

The system automatically detects expired documents and sends notifications.

```

Document Renewal Workflow

```

Renew expired documents and keep complete history with renewal date tracking.

```

Automatic Daily Status Update

```

A scheduled action runs automatically every day to update document states and trigger email notifications without any manual intervention.

  • Automatic status updates.
  • Expiring Soon detection.
  • Expired document detection.
  • Automatic email notifications.
  • Prevent duplicate emails.
  • Runs daily in the background.
```
